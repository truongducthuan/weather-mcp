# Weather MCP App for ChatGPT

Weather dashboard widget sử dụng Fractal MCP SDK, hiển thị thông tin thời tiết real-time trong ChatGPT.

## 🌟 Features

- ✅ Thông tin thời tiết real-time
- ✅ Interactive widget UI với charts
- ✅ Celsius/Fahrenheit converter
- ✅ Search history tracking
- ✅ Dark/Light theme support
- ✅ Responsive design

## 📋 Prerequisites

- Node.js 18+
- npm hoặc yarn
- ChatGPT Plus account
- Render account (free tier)

## 🚀 Quick Start

\`\`\`bash

# Clone repo

git clone <your-repo-url>
cd weather-mcp-app

# Install dependencies

npm install

# Build

npm run build

# Run locally

npm start
\`\`\`
